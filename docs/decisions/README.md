## Purpose

Decision records explain **why** significant architecture, runtime, hardware-binding, and integration choices were made.

## Migration status

The canonical decision records are being migrated here from the compatibility path [`../../decision-logs/`](../../decision-logs/). Existing IDs and historical content are preserved.

## Rule

A decision establishes intent/rationale. It does not establish implementation or validation. Superseded decisions remain preserved as history.
