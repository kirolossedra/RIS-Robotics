## Purpose

This directory stores image evidence referenced by Husky troubleshooting records. Images are grouped by the troubleshooting issue that owns the evidence so the Markdown record and its media remain traceable.

## Subdirectories

| Directory | Issue | Evidence |
|---|---|---|
| [`TS-001/`](TS-001/) | TS-001 — onboard computer power failure | User power panel, onboard-computer DC input, 12 V harness overview, and split-harness connector photographs |

`TS-001/` is currently the only child directory and contains no further subdirectories, so recursion terminates there.

## Placement rule

New issue-specific image sets should be placed under `images/<ISSUE-ID>/`, and this README plus the owning troubleshooting record must be updated together.
